三个圆环图表的共同点

  • 每个卡片高度一样：400px
  • 标题高度一样：28px（字号 18px）
  • 圆环内圈 30%，外圈 50%，圆心在卡片 42% 位置
  • 圆环顶部都会超出卡片 5px
  • 圆环底部到卡片底部都是 59px

三个圆环图表的不同点

  • 提交百分比：图例在右侧竖排，2 项，不占底部空间
  • 分类细分：图例在底部横排，6 项分两行，从 305px 处开始
  • 积分细分：图例在底部横排，6 项分两行，从 308px 处开始

负责间距的 CSS

在手机屏幕上（宽度 ≤ 768px），这三条规则控制间距：
statistics.html 
/* 手机屏幕下生效 */
#keys-pie-graph       { margin-top: 64px; }   /* 提交百分比和上方分隔线之间 */
.submission-counts     { margin-top: -85px; }  /* 正确/错误文字向上移动 */
#categories-pie-graph  { margin-top: 92px; }   /* 文字和分类细分之间 */

负责圆环位置的 JS

在手机屏幕上，把圆环的圆心往上挪，给底部图例腾空间：
statistics.js 
// 把圆心从正中间（50%）上移到 42% 的位置
series[0].center = ["50%", "42.06%"];

// 分类细分的图例往下挪到 305px
legend.top = 305;

// 积分细分的图例往下挪到 308px
legend.top = 308;
